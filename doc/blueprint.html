Product Overview

What are we building?

Promptly is a Git-inspired versioning platform for AI prompts. Teams save, diff, test, and rollback prompts with confidence — with automated scoring and multi-tenant collaboration baked in.

Problem → Solution
🚩
The Problem
Teams building AI products struggle to iterate on prompts safely and collaboratively. Issues include:
  • ✗ Ad-hoc changes with no history or rollback
  • ✗ No way to compare two prompt versions objectively
  • ✗ Inconsistent model behavior after prompt changes
  • ✗ No collaborative workflow — prompts in spreadsheets or Notion
💡
The Solution
Promptly provides a Git-inspired workflow designed specifically for prompt engineering teams:
  • ✓ Full version history with diffs and one-click rollback
  • ✓ A/B experiments with automated AI scoring and winner detection
  • ✓ Multi-tenant team workspaces with RBAC and audit trails
  • ✓ Works with any OpenAI-compatible API (Mistral, GPT-4, etc.)

Non-Functional Requirements
⚡
Performance
REST API responses ≤ 200ms (excluding AI calls). AI calls have a 30s timeout with graceful error handling. Experiment jobs run asynchronously — UI polls for completion status every 2s. Database queries must use indexed tenantId + promptId lookups.
🔒
Security
JWT tokens expire in 24h with refresh token rotation. Tenant isolation enforced server-side on every query — no cross-tenant leakage possible client-side. API keys encrypted at rest (AES-256). Rate limiting on auth routes (10 req/min). Input sanitization via Zod schemas.
📦
Scalability
Stateless Express servers deployable behind a load balancer. Neon Postgres auto-scales with connection pooling. BullMQ with Redis for job queues allows horizontal worker scaling. AI adapter layer is stateless — workers can scale independently of the API.
🛠️
Developer Experience
Hot-reload with Vite (frontend) and nodemon (backend). Zod-based validation with auto-generated TypeScript types. DB migrations versioned with Drizzle or Knex. Docker Compose for local Postgres + Redis. Seed scripts with demo workspace data. ESLint + Prettier enforced via pre-commit hook.
Roadmap
🔗 CI Integration
Built-in CI hooks to run prompt regression tests before merging code changes. Fail-fast if a new prompt version scores below a threshold.

Architecture Layers
🖥️ Frontend
React + Vite SPA. React Router v6 for navigation. React Query for server state + polling. Axios for API calls with JWT interceptor. Recharts for metrics visualization. Tailwind CSS with dark theme.
⚙️ Backend API
Node.js + Express. Zod for request validation. JWT middleware on all protected routes. Tenant-aware middleware extracts tenantId and scopes every DB query. BullMQ + Redis for async experiment job queue.
🗄️ Data Layer
Neon Postgres (serverless). Drizzle ORM with TypeScript types. All tables have tenant_id for row-level isolation. JSONB columns for flexible experiment configs and score breakdowns. DB migrations tracked in /server/migrations.
